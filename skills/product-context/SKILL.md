# Добавить контекст

Сохрани предоставленные материалы и обнови контекст продукта. Не запускай новое исследование. Вопросы «где мы и что дальше» без новых данных передавай product-status.

Прочитай [правила](../CONTRACT.md) и [запись памяти](../GRAPH-WRITES.md).
`<tools>` — каталог product-os-tools, как описано в [настройке](../os-setup/SKILL.md).

## Сохранить материал

1. Прочитай PRODUCT.md и только относящиеся к задаче записи графа.
2. Сохрани предоставленный оригинал без изменений в `sources/`. Для файла:
   `node <tools>/bin/product-os.js import <workspace> <file>`.
   Для текста сначала создай файл без пересказа, затем импортируй. Команда
   возвращает путь и ID материала; повторный импорт того же содержимого не создаёт дубль.
3. При необходимости добавь короткую заметку в reports/: что содержится в материале,
   источник каждого существенного утверждения, ограничения и неизвестное.
   Разделяй слова автора, наблюдения, интерпретацию и гипотезу. Это сохранение
   предоставленных сведений, не полноценное исследование или AJTBD-анализ.
4. Если материал уточняет существующий объект, подготовь операции с его стабильным
   ID и точным источником по GRAPH.md. Не создавай сегменты, связи и подтверждение
   спроса только по сходству слов. Не заменяй факты красивым резюме.
5. Записывай операции через `node <tools>/bin/product-os.js graph-write <workspace>
   <operations.json>` с актуальной expectedRevision. Сначала оригинал, затем память.
   Не редактируй research-graph.json вручную. Сохраняй историю противоречий.

Паспорт обновляй только новыми сведениями о самом продукте. Следующие действия
записывай лишь когда владелец их выбрал или уже поручил; совет не становится задачей.

## Границы

- Нет платёжных фактов — нет вывода о доказанном спросе или прибыли.
- Нет источника — сведение остаётся предположением, а не доказательством.
- Если нужна отдельная работа, назови её человеческими словами. Не предлагай
  команды отсутствующих специализированных навыков.
- Не публикуй пользовательские материалы и не отправляй их третьим лицам.

Готово: оригинал сохранён; добавленные сведения имеют источник; фактический итог
записи проверен. При чтении файлы и состояния остаются без изменений.
