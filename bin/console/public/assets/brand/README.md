# Product OS · Opora assets

The owner chose the Opora direction on 26 September 2026. These are original
geometric mark assets for Product OS. The full application rules are in the
repository's `BRAND.md`; UI tokens and the `brandSignature` component own runtime
presentation.

`mark-ink.svg`, `mark-accent.svg`, and `mark-inverse.svg` share the same 64×64
geometry. `wordmark-*.svg` combine that mark with Source Serif 4 lettering converted
to vector outlines at weight 600, optical size 40. Source Serif's OFL license lives
in `../fonts/source-serif-4/LICENSE.txt`; the font is not claimed as original work.

`favicon.svg` responds to the browser tab's colour scheme. `app-icon.svg` is the
square icon master. The PNG files name their actual pixel dimensions. The mark was
inspected at 16/32/64 px, and the square composition was checked with a circular crop.

These files are brand assets, not research evidence. No trademark or consumer
recognition claim follows from the owner's direction choice.
