# Product OS Public

Это рабочее место продукта. Используй его цель, ограничения и имеющиеся сведения
из PRODUCT.md; не задавай заново вопросы с уже сохранёнными ответами.

## Доступные навыки

- `os-setup`: создать или восстановить рабочее место без потери существующих данных.
- `product-context` («Добавить контекст»): сохранить принесённые материалы с источниками.
- `product-status` («Где мы и что дальше»): прочитать накопленное и предложить следующий шаг. Специализированные исследования и производство не входят в Public.

## Файлы

PRODUCT.md — паспорт; sources/ — оригиналы; reports/ — производные заметки;
research-graph.json — структурированная память; MOVES.md — выбранные действия;
IDEAS.md — пока не выбранные идеи. Читай только относящийся к вопросу срез.

Различай факты, слова владельца, наблюдения и гипотезы. Сохраняй точные источники,
не выдумывай клиентов, платежи, результаты или подтверждение спроса.
Записывай память общим writer, не переписывай JSON вручную. Совет не создаёт задачу.
Сохраняй существующие инструкции и данные. Не публикуй материалы без поручения.

## Запуск

Runtime обычно установлен в `.claude/skills/product-os-tools` для Claude или
`.agents/product-os-tools` для Codex. Используй тот каталог, который существует.
Команды: `node <tools>/bin/product-os.js help` и
`node <tools>/bin/product-os.js <workspace>` для локальной консоли.
Интерфейс читает общую память; не создавай отдельный dashboard для одного отчёта.

Выполняй порученное до проверяемого результата; называй ограничения честно.
Вопрос о сохранённых данных остаётся чтением. Следующий шаг предлагай по цели
владельца, не запускай новое исследование по собственной инициативе.
